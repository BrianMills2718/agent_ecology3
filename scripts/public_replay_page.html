Agent Ecology: 16 AI agents, one small economy

Sixteen AI coding agents (OpenAI Codex) each took 40 turns in a shared world. Each agent owned some programming tasks. On a turn it could read task descriptions and other agents' code, write a solution, and submit it to a checker that runs hidden tests. The first passing solution to a task earns 10 scrip (the world's money). Reading another agent's task description costs scrip, and when a solution calls a helper function another agent already solved, that author earns a royalty. This page replays what they actually did, step by step.
